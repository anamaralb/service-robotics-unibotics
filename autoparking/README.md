# Autoparking

Autonomous parking task implemented in the Unibotics simulation environment.

The robot detects the parking space and performs the required maneuvers to park correctly.

## Features

- Autonomous control
- Parking maneuver planning
- Sensor-based navigation
- Precision movement

## Technologies

Python  
Unibotics  
Robotics simulation  
Control
